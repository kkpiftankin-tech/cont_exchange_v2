# /experiment — автоформирование выжимки прогона для эксперта

Назначение: закрыть требование владельца «нужна **генерация** документов в
отдельном каталоге для анализа экспертом по трейдингу». Журнал больше не пишется
руками — каркас выжимки формируется из **живых данных dev**, человек добавляет
только «Вывод».

Вход: `$ARGUMENTS` — свободный текст. Выдели из него (или спроси кратко, если
неясно): **гипотезу** прогона, **что менялось** (флаги/конфиг/код), **окно** SQL
(деф `6 hours`), **id** (деф `ГГГГ-ММ-ДД-ЧЧММ`). «Вывод»/решение по умолчанию
оставь «(заполнить вручную)», если пользователь не дал.

## Шаг 1. Синхронизировать генератор на dev

Генератор `Testing/ce_experiment_summary.sh` читает живой dev (docker/psql). На
dev синхронизируй **только** этот скрипт (НЕ `.env-example` — память
[dev-env-file-is-envexample]):

```bash
rsync -a Testing/ce_experiment_summary.sh nik@ubuntu-dev:/home/nik/cont_exchange_v2/Testing/
```

## Шаг 2. Прогнать генератор на dev, захватить вывод

```bash
ssh nik@ubuntu-dev "cd /home/nik/cont_exchange_v2 && \
  RUN_ID='<id>' RUN_DATE='<дата>' WINDOW='<окно>' \
  HYP='<гипотеза>' CHANGE='<что менялось>' DECISION='<вывод или (заполнить вручную)>' \
  bash Testing/ce_experiment_summary.sh"
```

Вывод состоит из markdown-выжимки и последней строки `JOURNAL_ROW: | … |`.

## Шаг 3. Разложить вывод в репозиторий (локально)

1. **Выжимка** — всё, КРОМЕ строки `JOURNAL_ROW:`, запиши в
   `docs/experiments/EXP-<id>.md` (Write).
2. **Строка журнала** — содержимое после `JOURNAL_ROW: ` (начинается с `| `)
   допиши последней строкой таблицы в `docs/experiments/journal.md` (Edit:
   добавь после последней существующей `| …` строки).

Генератор на dev — журнал/файлы НЕ трогает (журнал живёт в локальном репо);
раскладку делает этот скилл.

## Шаг 4. Доложить и предложить «Вывод»

Сообщи пользователю: путь к `EXP-<id>.md`, ключевые числа (W·c, причины 1/3,
филлы), что раздел «Вывод» ждёт его решения (принять/отклонить гипотезу, следующее
действие). Если пользователь дал вывод в `$ARGUMENTS` — он уже вписан. Спроси,
коммитить ли выжимку+журнал (коммит — только по явной просьбе).

## Замечания

- Генератор даёт **каркас** (профиль, риск, W·c=0, исполнение, причины 1/3 —
  pending-поля MTM/σ помечены честно). Глубокий анализ (перцентили σ, модели) —
  по-прежнему вручную в тот же `EXP-<id>.md`, если нужен; «текста немного» —
  правило каталога.
- `docs/feedback/` — ДРУГОЙ канал (замечания с фронта/CLI, `inbox.md`→`/triage`),
  к экспертному журналу отношения не имеет. Не путать.
- Связано: навык `rebuild-service` (перед прогоном убедись, что затронутые сервисы
  пересобраны), `docs/experiments/README.md`.
