# Value Proposition

Что получает каждый сегмент пользователей.

## Liquidity Trader

- Контролируемый профиль исполнения во времени.
- Прогноз IS с доверительным интервалом до отправки.
- Защита от front-running.

## Market Maker / LP

- Экономически устойчивая среда: компенсация inventory-риска в slope CSLO.
- Меньше токсичного потока по сравнению с CLOB.

## Client Integrator / Broker

- Стандартизованный контракт на flow orders.
- Аудируемая отчётность по IS, VWAP, fill rate.
- Готовые алгоритмы (TWAP/VWAP/optimal) поверх FOB.

## Operator

- Полный обзор состояния платформы, kill-switch.
- Регуляторная отчётность из ClickHouse и risk_events.

См. также [stakeholders.md](stakeholders.md).

## Ценность полосы интернализации (F-18 v2)

Относится к фиче [F-18 «CE Virtual Counterparties»](../02-system/features/F-18-ce-capital-position-hedge/) (модель v2, под ADR-061). Бизнес-требования — [goals.md, BR-F18v2-01..06](goals.md#f-18-v2-интернализация-через-виртуальных-контрагентов).

Полоса `±q` — механизм **интернализации встречного клиентского потока**: биржа не бежит хеджировать каждую клиентскую сделку на внешнюю площадку, а даёт встречным потокам погасить друг друга внутри дилерского инвентаря и выводит наружу только излишек сверх полосы. Меньше внешних операций — ниже комиссии, спред и проскальзывание хеджа.

Эталонный прогон на 30 тактов (спека v2, `incoming-docs/2026-09-15-CE_algorithm_v2.md`):

| Показатель | С полосой `q=18/30` | Без полосы `q=0` |
| --- | ---: | ---: |
| Издержки хеджа | 182,73 USD | 495,06 USD |
| Спред, собранный с клиентов | 465,93 | 465,93 |
| **Итог** | **+203,18** | **−246,03** |

Полоса даёт **−63 % издержек хеджа** и разворачивает экономику такта из убытка (`−246,03`) в прибыль (`+203,18`).

> **Оговорка (не универсальный выигрыш).** Ценность полосы возникает **только при наличии встречного клиентского потока** — именно его она интернализует. Без встречного потока гасить нечего, и полоса лишь задерживает необходимый хедж, ухудшая результат. Полоса — это механизм внутренней компенсации потоков, а не бесплатное улучшение при любых условиях.
