| F15-11        | $\text{FillRate} = \sum \text{execqty} / \sum Q_{\max} \cdot 100\%$                | replay_step_journal; ⚠ при `sum(Q_max)=0` → `no_requested_volume=true`, `fill_rate=0`                                                                                                  | ✅     |

| F15-27        | `totalPnL = sum(incremental_pnl)`                                                   | replay_step_journal::AggregateSummary                                                                                                                                                  | ✅     |
| F15-28        | `avgIS` — volume-weighted: $\text{avgIS} = \sum (P^{\text{avg}}_i - P^{\text{decision}}_i) Q^{\text{exec}}_i / \sum Q^{\text{exec}}_i$ | replay_step_journal; `avgis_rule='volume_weighted'` зафиксировано в summary | ✅     |
| F15-29        | `avgVWAP = sum(execqty * execprice) / sum(execqty)`                                | replay_step_journal                                                                                                                                                                    | ✅     |
| F15-30        | `maxDrawdown = max(peak(t) − cumPnL(t))`                                            | replay_step_journal; rolling peak                                                                                                                                                      | ✅     |
| F15-31        | `avgSolveTime` — среднее `solve_time_ms` по батчам                                  | replay_step_journal                                                                                                                                                                    | ✅     |
| F15-32        | `decision_price` — mid от bestBid/bestAsk; fallback на clear_price                  | replay_step_journal; `decision_price_source='marketdata_mid_with_clearprice_fallback'` зафиксировано в summary                                                                          | ✅     |
| F15-33        | Граничный случай: `std(PnL) = 0` → `Sharpe = 0`                                     | replay_step_journal; покрытие `replay_summary_aggregation_test.cpp`                                                                                                                    | ✅     |
| F15-34        | Граничный случай: `sum(Q_max) = 0` → `fill_rate = 0`, `no_requested_volume = true` | replay_step_journal; покрытие `replay_summary_aggregation_test.cpp`                                                                                                                    | ✅     |
