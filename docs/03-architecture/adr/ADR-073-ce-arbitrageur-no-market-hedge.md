# ADR-073 — CE-арбитражёр без рыночного хеджа

> **Статус: proposed.** Заготовка этапа 2 плана
> [F-18-remediation](../../implementation-plan/F-18-remediation.tasks.md).
> Содержание дорабатывает `trading-domain-specialist` + `solution-architect`
> после сессии 1 с экспертом (вопрос: «нужен ли рыночный хедж арбитражёра
> вообще»). Ниже — предложение, не принятое решение.

## Контекст

Экспертный разбор (HEAD 02eafef) и проверка на dev показали: две рыночные ноги
арбитражёра (ADR-069, знаки src −f, dst +f) торгуют в **ту же сторону и объём**,
что переводчики тех же площадок. Подтверждено на живых данных: net_buy
переводчиков ≈ net_buy арбитражёров на каждой площадке (okx 14:00 T −1.704 /
A −1.704). Следствие: каждая межбиржевая сделка исполняется дважды, узловой
баланс **W·c = 0** (CE_algorithm_v2 §A6) нарушен (Σ позиций агентов в узле ≠ 0),
объём и дисбаланс площадок удваиваются. По базовому документу CE_algorithm_v2
арбитражёр — «перевозчик» актива, его внешнее действие — перевод, рыночного
риска у него нет; ADR-065 Q2 временно заменил перевод хеджем, ADR-069 разделил
хедж на две ноги. Разбор показывает: это несовместимо с замкнутым клирингом.

## Решение (предлагается)

Арбитражёр **не эмитит рыночный хедж**. Его позиция = дисбаланс остатков
системы между площадками; заработок = тариф перевоза в клиринге + изменение
базиса на позиции (не изменение цены актива). Поток разворачивается собственным
сдвигом γ_A > 0 (ADR-071). Физическая перевозка актива между площадками (срок,
тариф) — отдельная будущая фича, не часть этого ADR.

## Альтернативы

- Оставить рыночный хедж, но **связать ноги** в атомарную пару (совместный
  объём BUY src + SELL dst). Отклоняется как предложение по умолчанию: даже
  связанная пара дублирует сделки переводчиков (два агента торгуют друг с другом
  через биржу, платя спред дважды).
- Статус-кво (ADR-069). Отклоняется: нарушает W·c=0, удваивает объём.

## Последствия

- `ProjectAgentDeltas`/ledger перестают порождать хедж-эмиссии для `A_*`.
- Экранный P&L арбитражёра декоррелирует с ценой актива (corr≈0).
- Инвариант W·c=0 восстанавливается; нетто системы по активу ≈0.
- Требуется форма учёта «дисбаланс как позиция» и его переоценка по базису.

## Обратимость

Обратимо флагом (арбитражёр-хедж on/off) на период валидации; откат = возврат
к ADR-069. После приёмки на ≥2-недельных данных флаг фиксируется.
