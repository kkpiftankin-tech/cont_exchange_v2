# ADR-073 — CE-арбитражёр без рыночного хеджа

> **Изменено 2026-10-20 ([ADR-080](ADR-080-ce-internal-clearing-without-barriers.md), уточнение владельца).** В части «арбитражёр не эмитит рыночный хедж» это решение заменяется: арбитражёры, как и переводчики, выходят на внешнюю биржу при достижении порога позиции, порог зависит от комиссии и платы за перевод между биржами. Остальное (позиция арбитражёра как дисбаланс остатков, разворот потока сдвигом `γ_A`) сохраняется. Пока выход не включён на dev, действует прежнее поведение (`CE_ARB_MARKET_HEDGE=0`).

> **Статус: accepted для валидации на dev (2026-10-14).** Решение принято владельцем в сессии
> 2026-10-14 (явное подтверждение «оба пункта по очереди») после диагностики клиринга

## Контекст

Экспертный разбор (HEAD 02eafef) и проверка на dev показали: две рыночные ноги
арбитражёра (ADR-069, знаки src −f, dst +f) торгуют в **ту же сторону и объём**,
что переводчики тех же площадок. Подтверждено на живых данных: net_buy
переводчиков ≈ net_buy арбитражёров на каждой площадке (okx 14:00 T −1.704 /
A −1.704). Следствие: каждая межбиржевая сделка исполняется дважды, узловой
баланс **W·c = 0** (CE_algorithm_v2 §A6) нарушен (Σ позиций агентов в узле ≠ 0),
объём и дисбаланс площадок удваиваются. По базовому документу CE_algorithm_v2
арбитражёр — «перевозчик» актива, его внешнее действие — перевод, рыночного
риска у него нет; ADR-065 Q2 временно заменил перевод хеджем, ADR-069 разделил
хедж на две ноги. Разбор показывает: это несовместимо с замкнутым клирингом.

## Решение (предлагается)

Арбитражёр **не эмитит рыночный хедж**. Его позиция = дисбаланс остатков
системы между площадками; заработок = тариф перевоза в клиринге + изменение
базиса на позиции (не изменение цены актива). Поток разворачивается собственным
сдвигом γ_A > 0 (ADR-071). Физическая перевозка актива между площадками (срок,
тариф) — отдельная будущая фича, не часть этого ADR.

## Альтернативы

- Оставить рыночный хедж, но **связать ноги** в атомарную пару (совместный
  объём BUY src + SELL dst). Отклоняется как предложение по умолчанию: даже
  связанная пара дублирует сделки переводчиков (два агента торгуют друг с другом
  через биржу, платя спред дважды).
- Статус-кво (ADR-069). Отклоняется: нарушает W·c=0, удваивает объём.

## Последствия

- `ProjectAgentDeltas`/ledger перестают порождать хедж-эмиссии для `A_*`.
- Экранный P&L арбитражёра декоррелирует с ценой актива (corr≈0).
- Инвариант W·c=0 восстанавливается; нетто системы по активу ≈0.
- Требуется форма учёта «дисбаланс как позиция» и его переоценка по базису.

## Обратимость

Обратимо флагом (арбитражёр-хедж on/off) на период валидации; откат = возврат
к ADR-069. После приёмки на ≥2-недельных данных флаг фиксируется.

## Реализация (обратимая, за флагом — решение не финализировано)

Флаг `CE_ARB_MARKET_HEDGE` (деф `1` = поведение ADR-069, ноль изменений).
При `0` — `detect_and_emit_band_breach_locked` (ledger_uc.cpp) для не-нумерарийного
арбитражёра делает ранний `return` без эмиссии AgentBandBreach: позиция копится как
дисбаланс, разворот потока — сдвигом `ce_arb_inv_skew_gamma` (γ_A>0, ADR-071).
⚠ При включении (`0`) ОБЯЗАТЕЛЬНО задать γ_A>0, иначе позиция без хеджа и без skew
уйдёт в runaway. Валидация на dev: `CE_ARB_MARKET_HEDGE=0` + γ_A>0 → ворота этапа 2
(W·c=0 каждый такт; объём хеджей площадки = объёму переводчиков; нетто по активу ≈0;
corr(P&L арбитражёра, ΔP_актива)≈0). Статус решения — за владельцем/экспертом (сессия 1).


## Параметры валидации (2026-10-14)

- Динамика позиции арбитражёра на цикле без рыночного хеджа: $b_{t+1}=b_t+G\,(\Delta-\Sigma c-\gamma_A b_t)_+$,
  $G=(\sum 1/\alpha)^{-1}\le\alpha_A=12$. Устойчиво при $0<G\gamma_A<2$, монотонно при $<1$; с учётом лага
  чтения позиций (≥ такт) брать $G\gamma_A<1$ ⇒ $\gamma_A<1/12\approx 0{,}083$.
  Предел позиции $b^*=(\Delta-\Sigma c)/\gamma_A$; клэмп $K_A\ge\Delta-\Sigma c$.
- Выбрано на dev: **γ_A = 0,03 ‰ на k-USDT** ($G\gamma_A\le 0{,}22$; при Δ−Σc≈0,5‰ предел ≈ 17 k-USDT),
  **K_A = 8‰** (без изменений). При прежнем γ_A = 0,005 предел был бы ≈ 100 k-USDT.
- Ворота этапа 2: объём рыночных хеджей арбитражёров = 0; W·c; нетто по активу; позиции арбитражёров
  ограничены $b^*$.
- Известное ограничение: при флаге 0 `z_lim/z_mkt` арбитражёра в UI показываются нулевыми (порог записывается
  после раннего return в `detect_and_emit_band_breach_locked`) — дефект наблюдаемости, не денежный.
- Миграция: исторические позиции ног, накопленные при хедже, остаются; сброс позиций не делался
  (чтобы не терять накопления сделок на экране) — позиции в окне наблюдения сходятся к $b^*$ самим клирингом.
- Совместно включена age-aware полка (ADR-075, `CE_AGE_DEAD_ZONE_K=1.0`, с 20:56 UTC): две корректировки
  действуют одновременно, эффект каждой по отдельности в окне после 21:06 разделить нельзя; до флипа
  эффект age-полки измерен отдельно (4-минутные окна).
