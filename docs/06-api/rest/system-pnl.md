# REST: GET /api/vector-clearing/system-pnl

Маршрут BFF (`frontend/api/server.js`). Отдаёт прибыль системы CE по реальным остаткам для блока «Система по остаткам» на экране «Клиринг»: текущие значения (считаются при запросе из остатков ledger и цен бирж) и ряд за окно (записан семплером раз в минуту).

## Параметры

| Параметр | Обязателен | Смысл |
| --- | --- | --- |
| `hours` | нет | окно ряда в часах, 1…168, по умолчанию 24 |

## Ответ 200

```json
{
  "window_hours": 24,
  "baseline_ms": 1792683000000,
  "current": {
    "trading": 114.2, "revaluation": 5210.7, "mtm_change": 5324.9, "mtm": 1955324.9, "mtm0": 1950000.0,
    "skipped": [],
    "by_currency": [
      { "currency": "BTC", "q0": 9.994241, "q": 9.973971, "dq": -0.02027, "m0": 82000, "m": 82210, "trading": -1666.3, "revaluation": 2098.6 }
    ]
  },
  "current_error": null,
  "points": [{ "t": 1792683060000, "trading": 0, "revaluation": 0, "mtm_change": 0 }],
  "has_data": true,
  "generatedAt": "2026-10-22T16:00:00.000Z"
}
```

| Поле | Смысл |
| --- | --- |
| `baseline_ms` | момент базы (первый замер или последний сброс статистики сделок); `null` — учёт ещё не начат |
| `current` | `null`, если базы или остатков нет; иначе значения на сейчас |
| `current_error` | `null`, `ledger_unavailable` (остатки не получены), `inputs_unavailable` (нет данных о ценах) или `ledger_restarted` (ledger перезапущен, остатки бирж обнулились, а семплер ещё не задал новую базу — до минуты; `current` не считается, чтобы не показать скачок на величину обнулённых остатков); экран показывает ошибку, а не «учёт не начат» |
| `current.trading` | торговый результат: $\sum (q-q_0)\,m$, USDT |
| `current.revaluation` | переоценка запасов базы: $\sum q_0\,(m-m_0)$, USDT |
| `current.mtm_change` | $T+V$, изменение стоимости остатков с базы |
| `current.carry` | `{trading, revaluation}`: накопленное до последнего перезапуска ledger, уже включено в `trading`, `revaluation` и `mtm_change`; экран показывает пометку, если оно не нулевое (ADR-084 п. 8) |
| `current.skipped` | валюты с остатком, по которым нет цены (в итог не входят) |
| `current.by_currency` | остатки и вклады по валютам от текущей базы (перенос через перезапуск ledger в них не входит, он только в итогах) |
| `points[]` | ряд за окно, начиная с метки последнего сброса статистики сделок (старые точки после сброса не показываются; перезапуск ledger ряд не обрывает, так как каждая точка включает перенос): `t` (мс), `trading`, `revaluation`, `mtm_change`; не более 500 точек, в интервале берётся последняя |

## Ошибки

| Код | Причина |
| --- | --- |
| 502 | ошибка PostgreSQL или расчёта (`{"error":"system_pnl_error"}`); отсутствие таблиц ошибкой не считается |
| 503 | PostgreSQL недоступен |

Нет таблиц или базы — ответ 200 с `current: null`, `has_data: false`: экран пишет, что учёт начнётся при ближайшем замере.

## Экран

Блок над таблицами живой панели «Позиции агентов»: три числа (торговый результат, переоценка запасов, итого к базе), линейный график за выбранное окно (1 ч, 6 ч, 24 ч, 7 дн), таблица «по валютам», время базы и пояснения. Браузер ничего не считает.
