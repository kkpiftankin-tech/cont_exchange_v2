# PostgreSQL Table: `hedgeflows`

> **Status:** ❌ DDL отсутствует в [`infra/postgres/init.sql`](../../infra/postgres/init.sql). Создание — задача T-F12-201 в [implementation plan](../implementation-plan/F-12-execution-hedge.tasks.md#t-f12-201).

## Owner

[venue-execution-adapter](../05-components/venue-execution-adapter/overview.md) — единственный writer. Read access: REST gateway (GET `/api/v1/hedge/flows`), backtest-replay.

## Purpose

Источник истины для сессии хеджа одного `ExecutionIntent`. Один HedgeFlow содержит:
- параметры цели (`target_qty`, `target_notional`, `reference_mid`, `timeout_ms`);
- агрегированные результаты (`filled_qty`, `avg_fill_price`, `tot_fee`, `hedge_pnl`);
- статус (`OPEN` → terminal).

Связи:
- 1:N с [`child_orders`](child-orders.md) — все child orders по этому HedgeFlow.
- N:1 с `execution_reports` (ClickHouse) — каждый ExecutionReport содержит `hedge_flow_id`.

## DDL (target)

```sql
-- F-12 Execution Hedge: hedgeflows table.
--
-- Lifecycle: OPEN -> COMPLETED | UNDERFILLED | REJECTED | RISK_REJECTED | CANCELLED
--
-- Statuses соответствуют fob.hedge.v1.HedgeFlowStatus.
-- Decimal precision (24,8) согласован с IN-005 §1; для согласованности с
-- остальной OLTP (flow_orders 38,18) может быть расширен — open question.

CREATE EXTENSION IF NOT EXISTS pgcrypto;

CREATE TABLE IF NOT EXISTS hedgeflows (
    hedge_flow_id    UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    intent_id        UUID NOT NULL,
    batch_id         TEXT,                       -- back-ref в F-04 BatchResult
    provider_id      VARCHAR(64) NOT NULL,
    symbol           VARCHAR(32) NOT NULL,        -- internal instrument symbol (e.g. BTC/USDT)
    side             VARCHAR(4) NOT NULL CHECK (side IN ('BUY', 'SELL')),
    source           VARCHAR(32) NOT NULL CHECK (source IN ('AUTO_BATCH', 'MANUAL_OVERRIDE', 'BACKTEST')),

    -- target
    target_qty       NUMERIC(24,8) NOT NULL CHECK (target_qty > 0),
    target_notional  NUMERIC(24,8) NOT NULL,
    reference_mid    NUMERIC(24,8),
    timeout_ms       INT NOT NULL DEFAULT 5000,
    max_slippage_bps INT,                        -- override default по urgency

    urgency          VARCHAR(8) NOT NULL CHECK (urgency IN ('LOW', 'MEDIUM', 'HIGH')),

    -- aggregates (обновляются при каждом ExecutionReport)
    filled_qty       NUMERIC(24,8) NOT NULL DEFAULT 0 CHECK (filled_qty >= 0),
    avg_fill_price   NUMERIC(24,8),
    tot_fee          NUMERIC(24,8) NOT NULL DEFAULT 0,
    hedge_pnl        NUMERIC(24,8),

    -- lifecycle
    status           VARCHAR(20) NOT NULL DEFAULT 'OPEN'
        CHECK (status IN ('OPEN','COMPLETED','UNDERFILLED','REJECTED','RISK_REJECTED','CANCELLED')),
    error_code       TEXT,
    error_message    TEXT,

    created_at       TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at       TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    completed_at     TIMESTAMPTZ,

    -- consistency
    CONSTRAINT hedgeflows_filled_le_target CHECK (filled_qty <= target_qty * 1.01),  -- допускает overfill до threshold
    CONSTRAINT hedgeflows_terminal_completed_at CHECK (
        (status = 'OPEN' AND completed_at IS NULL) OR
        (status != 'OPEN' AND completed_at IS NOT NULL)
    )
);

-- idempotency: один intent_id -> один HedgeFlow
CREATE UNIQUE INDEX IF NOT EXISTS hedgeflows_intent_id_uniq ON hedgeflows (intent_id);

-- частые фильтры
CREATE INDEX IF NOT EXISTS idx_hedgeflows_provider_status ON hedgeflows (provider_id, status);
CREATE INDEX IF NOT EXISTS idx_hedgeflows_symbol_status ON hedgeflows (symbol, status);
CREATE INDEX IF NOT EXISTS idx_hedgeflows_batch_id ON hedgeflows (batch_id) WHERE batch_id IS NOT NULL;
CREATE INDEX IF NOT EXISTS idx_hedgeflows_created_at ON hedgeflows (created_at DESC);

-- watchdog: открытые HedgeFlow с timeout
CREATE INDEX IF NOT EXISTS idx_hedgeflows_open_timeout
    ON hedgeflows (created_at, timeout_ms)
    WHERE status = 'OPEN';
```

## Retention

- Active rows (status=OPEN): без retention (всё время open).
- Terminal rows: 365 дней в OLTP; long-term archive в ClickHouse `execution_reports` (90+ дней) + S3 long-term (за пределами scope).

## Backup

- pg_dump nightly.
- WAL streaming для PITR.

## Consistency / Transactionality

- INSERT hedgeflows + первый INSERT child_orders в одной транзакции (atomic creation).
- UPDATE hedgeflows.filled_qty/avg_fill_price/status выполняется в транзакции с UPDATE child_orders.
