# CE Virtual Counterparties — golden reference (Python)

Эталонная реализация алгоритма CE-агентов (ADR-055…059) для golden-тестов
[F-05A-CE-agents-test-plan](../../features/F-05A-CE-agents-test-plan.md) (раздел G-CEA).
C++ реализация Этапа 1 (T-CEA-101…107) обязана давать те же потоки/позиции с точностью
**1e-9**.

## Файлы

- `agents_vc.py` — модель: граф узлов «валюта@площадка», агенты (переводчик/связка/запас),
  единая кривая с мёртвой зоной `f(σ)=α·sign(σ*−σ)·max(0,|σ*−σ|−c)`, клиринг как
  минимизация выпуклого потенциала `Φ(x)=Σ½α((|σ−σ*|−c)₊)²`, разложение PnL и позиции.
- `agents_sim.py` — прогоны A–D (порог по разрыву, полоса запаса, дрейф марки, 400 тактов ×
  3 политики) + рисунки (в `img/`, не коммитятся).
- `golden-vc.txt` — эталонный вывод `agents_vc.py` (один такт + абляции).
- `golden-sim.txt` — эталонный вывод `agents_sim.py` (числовые секции A–D).

## Запуск

```sh
python3 agents_vc.py     # один такт + «что будет, если убрать типы агентов»
python3 agents_sim.py    # A–D + PNG в img/
```
Требует `numpy`, `scipy`; `agents_sim.py` дополнительно `matplotlib` (Agg).

## Ключевые golden-значения (сверены с дизайн-записками)

Базовый такт (миды Binance 0 / OKX +0.35 / Kraken −0.20 ‰), марка μ=+0.0720‰:
- дисбаланс узлов ≤ 2.14e-9 (Wx=0 по узлам площадок);
- потоки: `T_O=+0.1268`, `T_K=−0.1051`, `A_BTC_OK=−0.1051`, `S_BTC_O=−0.0217`;
- PnL `+0.00114 USDT` = закрытая форма `½Σα(|d|−c)²₊`;
- позиция BTC `−0.02172` тремя способами (запас = котировки = продано переводчиками);
- абляции (оборот котировок / PnL): полный `0.2319/+0.00114`; без связок `0.0480/+0.00019`;
  без запаса `0.0981/+0.00025`; **без связок и запаса `0.0000/+0.00000`** (переводчики не
  могут торговать без источника — Ш-условие работоспособности).

Пороги (agents_sim §A): арбитраж `0.532‰`, позиция `0.584‰`. Полоса запаса (§B): при 0.02‰
доля заработка от позиции 28%; предел широкой полосы = чистый арбитраж `+1.3306 USDT`.

## Теоретическая валидация (IN-017, §11)

Отдельный эталон корректности стратегии CE-агентов — прототип `prototype_dealer.py` из статьи
[IN-017](../../../../incoming-docs/2026-09-28-dealer-two-continuous-exchanges-48590e82.md) §11
(в репозитории отсутствует; методология воспроизводима). Он валидирует замкнутые формулы
теоремы 1 симуляцией восьми «миров» по 400 суток и служит образцом методологии проверки:

- **Несмещённая оценка ценности** (свободна от шума переоценки запаса, `∫q\,dP` — мартингал):
  $$
  \hat c = \overline{\text{валовой доход}} - \overline{\text{импакт}} - \frac{\gamma\sigma^2}{2}\overline{q^2}.
  $$
  Проверять формулы CE стоит через `ĉ`, а не через сырой P&L (иначе проверка тонет в шуме
  переоценки ~0.01 руб/сут).
- **Пять стратегий на одних траекториях** (IN-017 таблица 3): оптимальная (`ĉ=0.917±0.010` при
  теории `0.919`); только биржа 1 (`0.152`) / биржа 2 (`0.318`) — сумма `0.470` вдвое меньше
  оптимума (**эффект координации 2×**); две независимые ноги на общем складе (`0.849`, хуже
  оптимума); близорукая (`γ=0`: P&L похож, но `q²=65.1`, глубоко убыточна по риску).
- **Стационарные распределения** (IN-017 рис. 9): `std(q)`, `std(D)` должны совпадать с
  формулами (16) теоремы 1 — прямой инвариант-чек для CE-симулятора.

Связь с CE: это эталон ДЕЙСТВУЮЩЕЙ калибровки `Γ=γσ²τ` (O1, [ADR-066 §Addendum](../../../03-architecture/adr/ADR-066-ce-band-threshold-gamma-definition.md)),
НЕ прямой golden (модель IN-017 — двухбиржевая, CE — node-graph). Формулы — карточка
[`CALC-CE-ANCHOR`](../../../04-domain/calculations/CALC-CE-ANCHOR.md). Fragment: IN-017-F17-11.
