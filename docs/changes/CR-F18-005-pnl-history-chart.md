## Реплика

Владелец, 2026-10-28: «Нужен график отображения изменения PnL со временем на панели PnL».

## Runtime (для реплик по экрану)

На вкладке «PnL» (`/hedge-pnl-live`) была таблица «Заработок агентов» (R, U, R+U по внутренней, внешним биржам и итого, ADR-087) и старый график накопленного хедж-PnL из ClickHouse. Заработок агентов во времени показывался только по клику на агента в панели «Живые позиции», только для внешней группы и только по одному агенту; итоги по охватам и внутренняя группа во времени не записывались.

## Анализ (подъём)

| Р | Артефакт | Что сказано | Совпадает |
|---|---|---|---|
| Р8 | `AgentPnlChart.js`, `pnlChartModel.js` | график одного агента: R, U, R+U, S по записанной истории `ce_agent_pnl_history` | Да — переиспользуется (модель шкал и линии вынесены в общий `PnlLineChart`) |
| Р12 | `samplePnlHistoryOnce`, `agent_pnl_history.js` | история пишет внешнюю группу агента раз в минуту | Нет — нет внутренней группы и итогов по охватам |
| Р7 | `ce_agent_pnl_history` | колонки внешней группы и выгоды | Нет — не хватает внутренней группы и таблицы итогов |

## Решение (по умолчанию, без вопросов владельцу)

- Графика итогов нет в ledger как истории, поэтому BFF, как и для истории агентов, пишет раз в минуту итоги ledger (`GetAgentPnl`: все агенты, переводчики, арбитражёры) в новую таблицу `ce_pnl_totals_history` и внутреннюю группу агента в две новые колонки `ce_agent_pnl_history`. График читает записанное; расчёта на фронте нет.
- График на вкладке: охват (все / переводчики / арбитражёры; один агент — клик по строке таблицы), группа (итого / внутренняя биржа / внешние биржи), ряды R, U, R+U, окна 1 ч, 6 ч, 24 ч, 7 дн. Выгода по теории S остаётся только на графике агента в панели «Живые позиции».
- Неизвестное — разрыв линии (null), не ноль; итого = внутренняя + внешние считает BFF для отображения, неизвестная часть даёт null.

## Решения и риски

- История начинается с выкладки: значения внутренней группы и итогов до неё не записаны и по определениям модели C′ не восстанавливаются.
- Порядок выкладки: frontend-api (создаёт таблицу и колонки при первом проходе), затем frontend-web. Ledger не меняется.
- Откат: образы BFF и web прежние; таблица и колонки остаются без использования (`PNL_HISTORY_SAMPLE_MS=0` останавливает запись).
