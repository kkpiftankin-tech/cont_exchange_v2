## Реплика

Владелец, 2026-10-28: «Сделайте дополнительный чекбокс, который набавляет комиссию на цену покупки».

## Runtime (для реплик по экрану)

На графике «Сделки на внешних биржах по парам» ([CR-F18-006](CR-F18-006-pair-trades-chart.md)) цена покупки показывалась без комиссии. Реальная комиссия бирж в `child_orders` не записана (поле `fee` нулевое: 100 % заявок за сутки), поэтому надбавку можно только оценить по ставкам.

## Решение (по умолчанию, без вопросов владельцу)

- Расчётная комиссия по типу заявки: лимитные (`LIMIT`, `POST_ONLY`; 99 % исполнений за сутки) — ставка maker, остальные (`MARKET`, `IOC`, `FOK`) — taker. Ставки те же, что использует ledger для оценки комиссии зоны хеджа: `ce_maker_fee_bps` и `ce_taker_fee_bps` из `f05a_clearing_config` (экран «Клиринг»), иначе значения по умолчанию (2 и 10 б.п.).
- Цена покупки с комиссией = цена + комиссия на единицу базовой валюты; считает BFF (SQL суммирует комиссию по заявкам, функция `buildPairTradesDto` даёт `buy_price_fee`, `buy_fee`, `fee`), фронт при включённом чекбоксе подставляет готовое поле в линию покупки. Цена продажи не меняется (по просьбе — только покупка).
- Чекбокс выключен по умолчанию, состояние запоминается в браузере; в подписи и подсказке видны ставки.

## Решения и риски

- Комиссия оценочная (не фактическая) и общая для всех бирж по типу заявки; различия тарифов бирж не учитываются.
- Зеркальная поправка цены продажи (вычитание комиссии) не включена; при необходимости добавляется вторым чекбоксом.
