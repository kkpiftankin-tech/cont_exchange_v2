## Реплика

Владелец, 2026-10-28, по вопросу OQ-F18v2-34 (п. 1: нужен ли зеркальный чекбокс комиссии для цены продажи): «Берём (1), но комиссия учитывается только на графике».

## Решение

- Добавлен второй чекбокс «− комиссия с цены продажи», независимый от «+ комиссия к цене покупки»: линия продажи показывает цену за вычетом расчётной комиссии, $P^{S,\text{ком}}=P^{S}-F^{S}/Q^{S}$, по тому же правилу (ставка maker для лимитных заявок, taker для остальных, ставки экрана «Клиринг») и тем же ставкам, что и надбавка к покупке.
- Комиссия — только отображение графика: считается в BFF для линий этого графика и не входит ни в заработок агентов (R, U, R+U), ни в хедж-PnL, ни в ledger и панель «Живые позиции» (записано инвариантом в карточке расчёта).
- Считает BFF (SQL суммирует комиссию продаж, `buildPairTradesDto` даёт `sell_price_fee`, `sell_fee`); фронт при включённом чекбоксе подставляет готовое поле. Состояние чекбокса запоминается в браузере, по умолчанию выключен.
