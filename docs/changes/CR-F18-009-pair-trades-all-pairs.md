## Реплика

Владелец, 2026-10-28: «Почему графики не по всем парам валют».

## Runtime (для реплик по экрану)

Блок «Сделки на внешних биржах по парам» показывал чекбоксы только для пар с исполненными хедж-заявками в выбранном окне, и по умолчанию отмечалась одна пара (самая активная). Поэтому график был виден по одной паре, а у остальных пар либо не было чекбокса, либо он требовал ручного включения. На dev по окну 1 ч данные есть у 3 пар, 6 ч и 24 ч — у 4, 7 дн — у 5; кросс-пара SOL/BTC без исполненных заявок с 26.10 (последняя 16:39), ETH/BTC — с 28.10 12:01, поэтому в коротких окнах их нет в ответе.

## Решение (по умолчанию, без вопросов владельцу)

- Чекбоксы показывают все пары, по которым за 7 суток были исполненные заявки (новое поле ответа `known_pairs`), а не только пары окна. Пара без сделок в окне неактивна и подписана «нет сделок за окно, последняя <дата>»: график строить не из чего, но пара не пропадает.
- По умолчанию (нет сохранённого выбора, либо сохранённый выбор не содержит известных пар) отмечены все пары со сделками в окне.
- Кнопки «все» и «снять»; выбор запоминается в браузере, имена пар, которых больше нет в списке, при следующем выборе отбрасываются.
- Числа графика не менялись; список `known_pairs` считает BFF отдельным запросом (кэш 10 минут), фронт лишь показывает.
