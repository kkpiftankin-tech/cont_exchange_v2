## Реплика

Владелец, 2026-10-29: «да» — на предложение после расследования инцидента с зависшим `in_flight` агентов OKX: выполнять `ensure_agent_position_table` один раз на процесс и отключить синхронный коммит для подключения ledger на dev.

## Решение

- **Причина (измерено 2026-10-29 19:15–19:25 UTC):** ledger не успевал за потоком — отчёты об исполнении приходили 6,9/с, он разбирал 2,0/с (лаг `ledger-exec` 25 тыс., отчёт об отмене хеджа приходил через ≈ 33 минуты). PG принимал ≈ 210 коммитов/с. Каждая запись позиции (`ApplyDelta`, `ApplyHedge`, `GetPositions`) выполняла три оператора: `create table if not exists`, `alter table … add column if not exists` (ACCESS EXCLUSIVE даже когда колонка есть) и сам запрос — под общим замком `mu_`. По модели A7 возврат неисполненного остатка идёт только по отчёту, поэтому при запаздывании отчётов `in_flight` копил неподтверждённые заявки (миллионы USDT).
- **Изменение кода:** `ensure_agent_position_table(pqxx::connection&)` выполняет DDL один раз на процесс в собственной короткой транзакции (`SET LOCAL lock_timeout = '5s'`, мьютекс и `atomic<bool>`, флаг — после успешного commit). Сбой DDL не теряет запись позиции: предупреждение в лог, повтор не чаще раза в 30 с. Если таблицу или колонку убрали при работающем ledger (SQLSTATE 42P01 / 42703), флаг сбрасывается и самовосстановление повторяется. `EnsurePnlSchema` по-прежнему использует DDL в своей транзакции (`ensure_agent_position_table_ddl`).
- **Настройка стенда (только dev):** в `LEDGER_POSTGRES_DSN` добавлен параметр `options=-c synchronous_commit=off`, действует только на подключения ledger (роль `cex` общая для всех сервисов, поэтому не `ALTER ROLE`). При падении сервера PG теряются последние ≈ 200 мс записей кэша позиций; для dev принято.
- Не сделано (записано в known-gaps): запись в PG под `mu_` (объединение записей агента за такт), частота эмиссии хеджей (≈ 7 намерений/с при 3–4/с исполнимых), ответ `ApplyDelta` при ошибке PG обнуляет кэш позиции в памяти, остальные `ensure_*` выполняют `create table if not exists` на каждый вызов.
