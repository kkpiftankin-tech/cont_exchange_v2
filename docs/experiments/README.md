# docs/experiments — выжимки для эксперта-трейдера

Каталог для анализа экспертом. По мере исполнения плана
[F-18-remediation](../implementation-plan/F-18-remediation.tasks.md) сюда
**генерируется** по одной сжатой выжимке на прогон (скриптом из журнала
прогона, не вручную). Правило: только ключевые числа и вывод, текста мало.

## Состав

- `journal.md` — реестр: одна строка на прогон (дата · ID · гипотеза ·
  изменение · результат · решение).
- `_template.md` — форма выжимки (копировать в `EXP-<дата>-<id>.md`).
- `EXP-*.md` — выжимки прогонов (по одной на прогон).

## Правила

- Один прогон → одна выжимка → одна строка в `journal.md`.
- Числа — с 95% ДИ, где есть повторы. Без прозы «кажется/вероятно».
- Каждая выжимка самодостаточна: паспорт даёт воспроизводимость (run_id, SHA,
  config_version, окно, флаги).
- Генерация — скриптом этапа 0 (генератор выжимки); ручные правки только в
  разделе «Вывод».
