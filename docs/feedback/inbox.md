# Входящие замечания (черновик)

Заполняется при просмотре системы. Одна строка — одно замечание. Ожидание
формулируй проверяемо: число, текст, состояние. Для чисел указывай входные
значения, если они видны на экране. Скриншоты — вложением к сообщению
`/triage`. После разбора строки переносятся в `docs/feedback/FB-<дата>.md`, а
эта таблица очищается.

| id | экран / маршрут | элемент | что видно | что ожидалось | важность | скриншот |
|---|---|---|---|---|---|---|
| | | | | | | |

Важность: `блокер` / `важно` / `косметика`.

Разбор: `/triage docs/feedback/inbox.md`.
