Реализация **не стартует**, пока владелец не подтвердит план §2 (см. review-summary §13). До этого ADR-061 нельзя перевести в `accepted`, и весь код-трек закрыт (`CLAUDE.md §0a` no-code-before-docs).

3. **Консолидация движков** клиринга `ce_agent_clearing` (Engine B — fallback) vs Engine A (ADR-062, открытый вопрос).
4. **`AGENT` — третий `party_type`**, не подтип клиента (ADR-063): у AGENT знаковый инвентарь без резерва/неотрицательности.
5. **Security CRITICAL-1/2** — до Э1 либо починить, либо явно принять как отслеживаемый риск с компенсирующим контролем:

> **Security MEDIUM-7 (жёсткий пререквизит):** до Э4 отвергнутая/просроченная band-заявка оставляет `c_j` заниженной ⇒ **Э4 (`CE_AGENT_A8`, возврат остатка) — пререквизит включения `CE_AGENT_BAND`, не follow-up**.
