## Аннотация

Предлагается единая выпукло-аналитическая постановка рынка непрерывных
заявок, в которой каждый агент задаёт мгновенную кривую спроса-предложения
как связь между состоянием позиции `Q_i`, скоростью торговли `Q̇_i` и общей
рыночной ценой `P`. Рассматриваются четыре эквивалентные формы описания:

- прямая кривая «цена → скорость» `V_i(Q_i, P)`,
- обратная кривая «скорость → цена» `P_i(Q_i, Q̇_i)`,
- лагранжиан мгновенных потерь `L_i(Q_i, Q̇_i)`,
- гамильтониан `H_i(Q_i, P)` как преобразование Лежандра-Фенхеля по
  скорости.

Показано, что совокупный рынок задаётся формулами:

```
H(Q_1,…,Q_m, P) = Σ_i H_i(Q_i, P)                              (сумма)
L(Q_1,…,Q_m, Q̇) = inf_{Σ_i Q̇_i = Q̇}  Σ_i L_i(Q_i, Q̇_i)        (инфимальная свёртка)
```

а цена клиринга `P*` эквивалентно определяется тремя способами:

1. как решение `Σ_i Q̇_i(Q_i, P*) = 0` (нулевой суммарный поток),
2. как субградиент `P* ∈ ∂_Q̇ L(Q_1,…,Q_m, 0)`,
3. как минимум агрегированного гамильтониана по цене:
   `P*(Q) ∈ arg min_P H(Q, P)`.

Для типовых агентов выписаны все четыре формы и приведены замкнутые
формулы клиринга в квадратическом семействе.

## §3.1 Переменные состояния

На рынке торгуется `n` активов, действует `m` агентов. Для каждого
агента `i = 1,…,m`:

- `Q_i ∈ ℝ^n` — текущий вектор позиции,
- `Q̇_i ∈ ℝ^n` — мгновенная скорость её изменения,
- `P ∈ ℝ^n` — общая рыночная цена.

Локальная постановка фиксирует момент времени: `Q_i` — данное состояние,
оптимизационная переменная — `Q̇_i`.

## §3.2 Четыре формы представления кривой

`L_i(Q_i, Q̇_i)` — собственная, полунепрерывная снизу, выпуклая по скорости
функция мгновенных потерь.

**(i) Прямая форма** «цена → скорость»:

```
V_i(Q_i, P) = arg max_v { ⟨P, v⟩ − L_i(Q_i, v) }
```

**(ii) Обратная форма** «скорость → цена»:

```
P ∈ ∂_{Q̇_i} L_i(Q_i, Q̇_i)
```

**(iii) Лагранжево представление** — `L_i(Q_i, Q̇_i)` напрямую.

**(iv) Гамильтоново представление** — преобразование Лежандра-Фенхеля
по скорости:

```
H_i(Q_i, P) := sup_v { ⟨P, v⟩ − L_i(Q_i, v) }                  (3.1)
```

**Предложение 3.2 (эквивалентность четырёх форм)**: при строго выпуклой
`L_i(Q_i, ·)` гамильтониан `H_i(Q_i, ·) = L_i(Q_i, ·)*` выпукл и
дифференцируем; кривые соответственно `V_i = ∇_P H_i`, `P_i = ∇_{Q̇_i} L_i`,
и кривые `V` и `P` — взаимно обратные.

**Замечание 3.3** (про гамильтоновы уравнения): корректная статическая
связь — `Q̇_i = ∂_P H_i(Q_i, P)`, НЕ `Q̇_i = ±∂H_i / ∂Ṗ_i`. Полные
канонические уравнения — это межвременной функционал, а не мгновенная
связь.

## §4.1–4.2 Совокупные кривые

**Прямая совокупная кривая**: `V(Q, P) = Σ_i V_i(Q_i, P)`.

**Условие клиринга**: `V(Q, P*) = Σ_i Q̇_i(Q_i, P*) = 0`.

**Обратная совокупная кривая** через инфимальную свёртку:

```
L(Q, Q̇) := inf_{Σ_i v_i = Q̇}  Σ_i L_i(Q_i, v_i)               (4.4)
P ∈ ∂_Q̇ L(Q, Q̇)                                                 (4.5)
P*(Q) ∈ ∂_Q̇ L(Q, 0)                                              (4.7)
```

## §4.3 Цена клиринга как множитель Лагранжа

Лагранжиан задачи (4.4):

```
J(v_1,…,v_m, P) = Σ_i L_i(Q_i, v_i) − ⟨P, Σ_i v_i − Q̇⟩         (4.8)
```

Условия первого порядка:

```
P ∈ ∂_{v_i} L_i(Q_i, v_i),  i = 1,…,m
Σ_i v_i = Q̇                                                     (4.9)
```

**Рыночная цена = общий множитель Лагранжа**, который выравнивает
индивидуальные предельные потери и обеспечивает баланс потока.

**Предложение 4.1 (агрегирование)**:

```
H(Q, P) = Σ_i H_i(Q_i, P)                                       (4.10)
L(Q, Q̇) = H(Q, ·)*(Q̇)                                          (4.11)
Q̇ ∈ ∂_P H(Q, P)  ⟺  P ∈ ∂_Q̇ L(Q, Q̇)                            (4.12)
0 ∈ ∂_P H(Q, P*)  ⟺  P* ∈ ∂_Q̇ L(Q, 0)                           (4.13)
```

**Следствие 4.2 (цена = минимум агрегированного гамильтониана)**:

```
P*(Q) ∈ arg min_P H(Q, P)  ⟺  Σ_i Q̇_i(Q_i, P*) = 0              (4.15)
```

## §4.4 Существование и единственность клиринга

**Предложение 4.3**: достаточные условия:

1. `L_i(Q_i, ·)` собственна, полунепрерывна снизу, суперлинейна.
2. `μ_i`-сильно выпукла по второй переменной, `μ_i > 0`.

Тогда `H_i ∈ C^1`, `H(Q, ·)` строго выпукл и коэрцитивен, цена клиринга
`P*(Q)` существует и единственна.

## §4.5 Квадратическое семейство — замкнутые формулы

Класс лагранжианов:

```
L_i(Q_i, Q̇_i) = (1/2) Q̇_i^⊤ M_i Q̇_i + ψ_i(Q_i) − a_i^⊤ Q̇_i    (4.16)
                M_i ≻ 0
```

Тогда:

```
P = M_i Q̇_i − a_i                                                (4.17)
Q̇_i = M_i^(-1)(P + a_i)                                          (4.18)
H_i(Q_i, P) = (1/2)(P + a_i)^⊤ M_i^(-1)(P + a_i) − ψ_i(Q_i)     (4.19)
```

С обозначениями `B := Σ_i M_i^(-1)`, `b := Σ_i M_i^(-1) a_i`:

```
H(Q, P) = (1/2) P^⊤ B P + b^⊤ P + const                          (4.21)
V(Q, P) = B P + b                                                (4.22)
P*(Q) = − B^(-1) b                                               (4.23)
L(Q, Q̇) = Σ_i ψ_i(Q_i) + (1/2)(Q̇ − b)^⊤ B^(-1)(Q̇ − b) + const  (4.24)
P(Q, Q̇) = B^(-1)(Q̇ − b)                                          (4.25)
```

**Цена клиринга в квадратической модели = взвешенный средний внешний
якорь, веса обратно пропорциональны "инерциям" агентов.**

## §5.1 Одномерные агенты (4 типа)

### 5.1.1 Стандартный агент

```
L(q̇) = (m/2) q̇² + a q̇,                  m > 0
p(q̇) = m q̇ + a
q̇(p) = (p − a) / m
H(p) = (p − a)² / (2m)
```

### 5.1.2 Безразличный по цене (m → ∞)

```
L(q̇) = I_{0}(q̇)                          (indicator at 0)
q̇(p) = 0  для всех конечных p
H(p) = 0
```

### 5.1.3 Безразличный по скорости (m → 0)

```
L(q̇) = a q̇
p(q̇) = a  для всех q̇
q̇(p) = ∞ если p > a, undefined если p = a, −∞ если p < a
H(p) = 0 если p = a, +∞ иначе
```

### 5.1.4 Инерционный агент с линейной комиссией

```
L(q̇) = (m/2) q̇² + a q̇ + c |q̇|,         c > 0
q̇(p) = shrink(p − a, c) / m              (zone of inaction [a−c, a+c])
H(p) = (max{|p − a| − c, 0})² / (2m)
```

## §5.2 Двумерные агенты (8 типов)

Матрица инерции `M_ρ` с корреляцией ρ ∈ (−1, 1):

```
M_ρ = | m_1                ρ √(m_1 m_2) |
      | ρ √(m_1 m_2)        m_2         |
```

Список типов:

1. **5.2.1** Стандартный (|ρ| < 1).
2. **5.2.2** Безразличный по цене первого актива (m_2 = ∞).
3. **5.2.3** Безразличный по скорости второго актива (m_2 = 0).
4. **5.2.4** Независимый (ρ = 0).
5. **5.2.5** Абсолютно-комплементарный (ρ ↑ 1).
6. **5.2.6** Абсолютно-субститутный (ρ ↓ −1).
7. **5.2.7** Стандартный с линейной комиссией (no-trade region — прямоугольник).
8. **5.2.8** Портфельный агент (factor `w`):

```
H(P) = (1 / 2μ) (w^⊤ P − a)²
Q̇(P) = (w / μ)(w^⊤ P − a)
L(Q̇) = α a + (μ/2) α²    if Q̇ = α w,  иначе +∞
```

Портфельный агент маркетит **линейную комбинацию цен** (индекс, спред,
корзину), а не отдельные активы.

## §6.1 Одномерные сценарии клиринга

### 6.1.3 N стандартных агентов (главный результат)

**Предложение 6.1**: пусть `L_i(q̇_i) = (m_i/2) q̇_i² + a_i q̇_i`.
Рынок эквивалентен одному стандартному агенту с:

```
m* = (Σ_i 1/m_i)^(-1)
a* = m* · Σ_i (a_i / m_i)                                       (6.11)
```

И тогда `q̇(p) = (p − a*) / m*`, цена клиринга `p* = a*`.

**Вес каждого якоря в цене клиринга обратно пропорционален индивидуальной
инерции**: чем меньше `m_i`, тем более "голосист" агент в статическом
клиринге.

### 6.1.4 Два агента с комиссией

Не сворачивается в одного стандартного агента: агрегированный
гамильтониан остаётся кусочно-квадратическим, прямая кривая —
кусочно-линейной.

## §6.2–6.3 Многомерная репликация

### Главная теорема репликации (§6.3.1)

Произвольный квадратический рынок `H(P) = (1/2)(P − A)^⊤ Λ (P − A)` с
`Λ ≻ 0` можно реализовать `n + r` агентами:

- `n` одноактивных агентов (по одному на каждый актив) с гамильтонианами
  `H_k(P) = (d_k/2)(p_k − A_k)²`;
- `r` факторных портфельных агентов с гамильтонианами
  `H_{n+ℓ}(P) = (1/2)((u^(ℓ))^⊤ (P − A))²`,

где разложение `Λ = D + U U^⊤`, `D = diag(d_1,…,d_n) ⪰ 0`, `U ∈ ℝ^(n × r)`.

**Минимальное число факторных агентов**:

```
r*(Λ) = min{rank(Λ − D) : D ⪰ 0, D diag, Λ − D ⪰ 0}             (6.41)
N*(Λ) = n + r*(Λ)
```

В двумерном случае `r*(Λ) ≤ 1` ⇒ всегда достаточно ровно 3 агентов.

## §6.2.5 Явная формула клиринга 3-агентного коррелированного рынка

Два одноактивных стандартных агента + один спред-агент:

```
H(P) = (p_1 − a_1)²/(2m_1) + (p_2 − a_2)²/(2m_2) + (p_1 − p_2)²/(2m_3)

p*_1 = (a_1(m_2 + m_3) + a_2 m_1) / (m_1 + m_2 + m_3)            (6.28)
p*_2 = (a_2(m_1 + m_3) + a_1 m_2) / (m_1 + m_2 + m_3)            (6.29)
p*_1 − p*_2 = m_3 / (m_1 + m_2 + m_3) · (a_1 − a_2)              (6.30)
```

Третий агент **масштабирует спред** в точном соответствии со своей
инерцией `m_3`.

## §7 Ключевые выводы

1. Индивидуальная кривая спроса-предложения = 4 эквивалентных объекта:
   `V_i(Q_i, P)`, `P_i(Q_i, Q̇_i)`, `L_i(Q_i, Q̇_i)`, `H_i(Q_i, P)`.
2. **Рыночная цена = общий множитель Лагранжа** для ограничения баланса
   потоков. Совокупная прямая кривая = сумма индивидуальных.
3. **Совокупный лагранжиан = инфимальная свёртка**, совокупный
   гамильтониан = **сумма**. Это canonical агрегирование в обратной,
   лагранжевой и гамильтоновой формах.
4. Квадратический класс — аналитически замкнутый. Цена клиринга — явная
   функция матриц инерции и внешних якорей.
5. Сингулярные предельные случаи (бесконечная инерция, идеальная
   ликвидность, чистый позиционный штраф) приводят к расширенно-значным
   функциям и многозначным кривым — это структурная особенность модели.

## §A Сингулярные случаи как пределы

1. **Полное безразличие**: `L_ε(q, q̇) = (ε/2) q̇²`, `ε ↓ 0`.
2. **Бесконечная инерция**: `(m/2) q̇²`, `m ↑ ∞`.
3. **Чистая риск-аверсия**: отсутствие штрафа скорости. Для численного
   стабильного клиринга всегда полезно добавлять малый регуляризатор
   `ε q̇² / 2`.
