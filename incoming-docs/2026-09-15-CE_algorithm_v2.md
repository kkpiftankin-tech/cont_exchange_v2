# Алгоритм такта CE: полное описание в новой постановке (v2)

> Провенанс: прислано пользователем 2026-09-15 инлайн-текстом; авто-архив-хук не сработал
> (аттач пришёл как inline). Сохранено вручную как immutable-источник для F-18 v2.
> Парный файл: `2026-09-15-CE_integration_plan.md`.

Агенты — только **переводчики** и **арбитражёры**. У каждого позиция стартует с нуля, может быть
отрицательной, и пока `|позиция| ≤ q`, наружу не уходит ни одной заявки. Ни склада, ни целевых
остатков, ни плеч запаса.

## Что изменилось по сравнению с прежним описанием

| | Было | Стало |
|---|---|---|
| агенты | переводчики, арбитражёры, **плечи запаса** | только переводчики и арбитражёры |
| узлы | площадки **плюс склад** | только площадки |
| позиция | `владение − цель`, по активу | накопленный неисполненный поток **агента** |
| стартовая позиция | ненулевой разложенный капитал | **ноль** у каждого агента |
| цель `target` | настройка казначейства | **отсутствует как понятие** |
| поле `committed` | отдельное от позиции | это **и есть** позиция |
| эмиссия заявок | каждый такт | **только** при выходе за полосу `±q` |
| куда падает прибыль | на денежное плечо запаса | на **счёт дома** (не агент) |
| сдвиг якоря | `ρ(Q−Q*) + ρ·committed` | `ρ·(своя позиция)` — одно слагаемое |

## 0. Величины

- **Узел** — пара «актив на площадке»: `BTC@Binance`. Один актив на двух площадках — два узла.
- **Переводчик** (`Q_BIN`, `Q_KRK`) — агент, меняющий на ОДНОЙ площадке актив на деньги (маркет-мейкер).
- **Арбитражёр** (`T_BTC`, `T_USD`) — перевозит ОДИН актив между площадками (логистика; тариф+срок, без цены).
- **Позиция агента** `c_j` — пообещал по клирингу и не отправил наружу, тыс. USDT; ноль на старте, знаковая.
- **Полоса** `q_j` — порог на `|c_j|`.
- **Промилле (‰)** — лог-отклонение от опорной `P₀=60000`. Премия `+3‰` = `60000·e^0,003≈60180`.
- **Марка** — средний мид площадок (для качества исполнения). **Нумерарий** — `USD@Binance`.

## Две книги биржи
- **Внутренняя книга** — четыре агента со своими кривыми (не стакан чужих заявок). Клиринг сводит кривые. Своих заявок биржа сюда не подаёт — она И ЕСТЬ эти кривые.
- **Внешние заявки** — то, что биржа шлёт на Binance/Kraken, только когда позиция вышла за полосу.
- **Расчётный слой** — остатки на счетах площадок (оборотный капитал).

## A0. Вход такта
Мгновенный снимок обоих стаканов (внутри такта не меняется). Встречный клиентский поток: клиент
купил BTC → биржа отдала актив немедленно и получила НАМЕРЕНИЕ выкупить обратно на площадке
(меняет владение немедленно, хедж — отложенное намерение в позиции переводчика).

## A1. Три числа из стакана
Одна кривая из трёх кусков. **Якорь** `m = 1000·ln(mid/P₀)`, `mid=½(bid+ask)`.
**Наклон** (консервативный минорант): `α = θ·min_{сторона,уровень} V(уровень)/d(уровень)`,
где `V`=накопленная стоимость до уровня, `d`=расстояние цены от мида в ‰, `θ`=запас (0,50).
Линия `α·d` не выше ломаной накопленной стоимости. **Полка** `c = комиссия + ½·|ln(ask/bid)|·1000`.

Пример Binance: `α=0,50·71,971=35,986`; `m=+0,0001‰`; `c=0,20+0,3333=0,5333‰`.

**Кривая агента:**
```
f(σ) = α·(σ − m − c),  σ > m + c    продаёт
       0,              |σ − m| ≤ c  полка
       α·(σ − m + c),  σ < m − c    покупает
```
`σ` — ставка клиринга (‰), `f` — поток (тыс. USDT/такт). У арбитражёра `m=0`, `c`=тариф
(0,20‰ BTC, 0,05‰ деньги), `α` — из пропускной способности маршрута.

## A2. Якорь: единственный сдвиг — от собственной позиции
```
σ*_j = m_j + ρ_j · c_j
```
`c_j` — СОБСТВЕННАЯ позиция агента; `ρ_Q=0,004` (переводчик), `ρ_T=0,002` (маршрут). A2 видит
позицию ДО A6 (после подтверждений и клиентской сделки, до накопления клиринга). Цели и отдельного
`committed` больше нет — позиция И ЕСТЬ неисполненное обещание.

## A3. Матрица баланса W
Строка — узел, столбец — намерение агента (±1 в узле). Квадрат 2×2:
```
            Q_BIN Q_KRK T_BTC T_USD
BTC@Binance  +1    0    −1    0
USD@Binance  −1    0     0   +1
BTC@Kraken    0   +1    +1    0
USD@Kraken    0   −1     0   −1
```
Общий случай (`V` площадок, `A` активов, актив 0 — нумерарий): узлов `V·A`, переводчиков
`V·(A−1)`, арбитражёров `A·(V−1)`, всего агентов `2VA−V−A`, ранг `W = V·A−1`, независимых кругов
`(V−1)(A−1)`, левое ядро одномерно — вектор `(1,…,1)` (свобода нумерария: цены `π` определены до
общей константы; закрепляется `π[USD@Binance]=0`).

## A4. Клиринг
```
max_f  Σ_j [ −σ*_j·f_j − c_j·|f_j| − f_j²/(2α_j) ]   при   W·f = 0
```
`−σ*f` выигрыш от торговли не по якорю; `−c|f|` полка (вычет); `−f²/2α` проскальзывание.
Функция = интеграл кривой A1 (`dU/df=0` даёт `f(σ)`). Цены узлов `π` — множители Лагранжа `Wf=0`,
ставки `σ = Wᵀπ`.
Общий: расщепление `f=x₊−x₋`, `x≥0`, `|f|=x₊+x₋` → QP (OSQP).
Квадрат: `f=λ·k`, `k=(+1,−1,+1,+1)`, скалярно:
```
S = Σ σ*_j·k_j,  C = Σ c_j·|k_j|,  A = Σ k_j²/(2α_j)
λ* = −(S+C)/(2A) если S<−C;  −(S−C)/(2A) если S>+C;  0 если |S|≤C (круг убыточен — пустой такт)
```
Внутренняя цена биржи переносит НЕ премию площадок, а стоимость доставки: `π(BTC@KRK)−π(BTC@BIN)`
= тариф перевоза. При нулевом потоке цены узлов не однозначны (ставка внутри полки).

## A5. Проверки перед действием
1. Узловой баланс `|Wf|<1e-6`. 2. Согласие двух решателей (замкнутая форма = OSQP).
3. Физическая исполнимость: объём заявки ≤ 95% остатка узла-источника.

## A6. Накопление позиций (наружу не идёт ничего)
```
c ← c + f
```
Полный шаг. Отрицательная позиция обязательна: `W·c=0`, базис ядра `(+1,−1,+1,+1)` — одна
компонента противоположна; требование `c≥0` даёт только `c=0` (нет оборота). Минимум в прогоне
`−18,000` тыс. Экономически — обещание продать раньше, чем актив доехал.

## A7. Полоса: эмиссия только при выходе за ±q
```
если |c_j| ≤ q_j: ничего; иначе: отправить наружу (|c_j|−q_j)·sign(c_j) и на столько же уменьшить c_j
```
Отправленное УХОДИТ из позиции в заявку (иначе повторная отправка). Заявка в `in_flight`; по
таймауту неисполненный остаток ВОЗВРАЩАЕТСЯ в позицию. Отдельного `committed` не нужно.
Две полосы: переводчик (`q=18`, риск незахеджированного запаса) и арбитражёр (`q=30`, размер партии
перевоза, рыночного риска нет). Размер заявки по СТОИМОСТИ: `qty ← излишек·1000/walk(qty)`, 2-3
итерации. Тип заявки по экспозиции (пассивный лимитник → агрессивный).

## A8. Подтверждения (единственный шаг, меняющий факт)
1. Приходы перевозов (`eta≤t`) на узел назначения.
2. Исполнения: `qty[BTC@v]+=sgn·fq`; `qty[USD@v]-=sgn·fq·px_факт/1000`;
   `realized += fq·(марка−px_факт)/1000·sgn`. Позицию агента НЕ трогаем (уменьшена на A7).
3. Таймауты: неисполненный остаток → в позицию по ПЛАНОВОЙ цене.
Край меряется к марке. Разрыв план/факт — отдельная величина (качество исполнения).

## Позиция биржи по каждой валюте
```
владение_a = Σ_площадки qty[a@площадка] + Σ in_transit[a]
Z_a = владение_a(t) − владение_a(0)
```
Старт с нуля. **Владение меняют РОВНО две вещи: сделка с клиентом и исполнение на площадке.
Клиринг, накопление позиций и перевозы владение НЕ меняют никогда.** Без клиентского потока `Z≡0`.

## Счёт дома (куда падает прибыль)
В стоимостных единицах баланс сходится; в натуральных `det W = (p_Kraken−p_Binance)/1000` —
вырождается при равных ценах. Один столбец «счёт дома» (единственная ненулевая клетка в узле
нумерария) восстанавливает ядро и забирает арб-прибыль (`= разница цен`). Счёт дома — НЕ агент:
нет якоря/наклона/полки/полосы, заявок не порождает (переменная-невязка). Остаток сметать в нумерарий.

## Незакрытое
1. Признание прибыли по факту расчёта (в прототипе разрыв до 6611 USD/1200 тактов).
2. Задержка перевоза (взята 3 такта).
3. Выбор `q` при `V>2` (полос столько же, сколько агентов).
4. Цены при пустом клиринге (нужна явная политика).

## Источники
Budish–Cramton–Kyle–Lee–Malec «Flow Trading» (NBER WP 31098): `Wx=0`, цены как множители Лагранжа,
продажа как отдельная заявка с отрицанием весов. Barzykin–Bergault–Guéant (2023): зона
интернализации, хедж к границе — прообраз полосы `±q`. Ho–Stoll (1981): снос котировки от запаса
(`ρ·c`). Constantinides (1986), Davis–Norman (1990): область бездействия при издержках. Проверка:
`ce_tick_v2.py` (27 проверок).
