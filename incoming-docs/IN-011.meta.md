## Notes

- IN-011 переводит F-09 с упрощённой модели «combo = независимые FlowOrder + combo_id» (текущие стабы) на полноценную модель: два режима исполнения (`orchestration_only`, `multileg_vector_solver`), 5 политик атомарности, векторный солвер, `ExecutionGroup`/`LegFill`, граф состояний OCO/bracket.
- Ключевое правило (§21): любая заявка с сохранением weights/ratio/spread/factor/budget/leverage/margin/portfolio-risk обязана идти через `multileg_vector_solver`; набор независимых FlowOrder допустим только как `orchestration_only` и не обещает multi-leg guarantees.
- Linked: F-02 (FlowOrder DTO — нога нормализуется к CSLO-параметрам), F-04 (batch cycle — grouped solve встраивается в клиринг), F-05 (reference prices для weights/spread), F-06/F-07 (grouped pre/post-trade risk, margin), F-11/F-12 (external legs, venue execution, compensating), F-15 (replay determinism для grouped execution — AC-F09-010).
- Out of scope MVP (§19): cross-venue true atomic, options solver, нелинейные Greeks, RL-routing, полный rollback внешних сделок, prime-broker netting.
