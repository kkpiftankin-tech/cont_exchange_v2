## Document Type

Academic / theoretical foundation reference (НЕ feature spec, НЕ UC,
НЕ runtime finding). Это математическая основа всей matching engine
формулировки:

- Continuous-order market formulation (4 equivalent curve representations).
- Hamiltonian / Lagrangian first-class trading-domain entities.
- Clearing price as Lagrange multiplier for flow balance constraint.
- Convex aggregation: sum of individual Hamiltonians + infimal convolution
  of individual Lagrangians.
- Quadratic family closed-form clearing.
- Multi-asset replication via factorial decomposition.
- Singular limiting cases (perfect liquidity, infinite inertia,
  pure risk-aversion).
