## Document Type

Feature spec (extension) — **F-05A**, расширение **F-05 Live Market Data** для
поддержки **F-09** `multileg_vector_solver`. Описывает преобразование внешних
дискретных orderbook levels (CEX/DEX/AMM) в векторные flow-сегменты `w_i`, сборку
матрицы `W` и QP-клиринг при `Wx = 0` (multi-asset / triangular clearing без
синтетической pair-book). Primary owner — Market Data / External Liquidity.

NON_FUNCTIONAL_REQUIREMENT, DOMAIN_ENTITY, GRPC_CONTRACT, KAFKA_TOPIC, DATA_MODEL,
SERVICE_SEQUENCE_HINT, TEST_REQUIREMENT, IMPLEMENTATION_HINT + UI/frontend scope +
два ADR-gap (surplus policy, QP solver).
