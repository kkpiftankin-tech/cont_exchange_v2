## Notes

### Аудит соответствия CE ↔ статья (2026-09-28, trading-domain-specialist)

Проведён при регистрации (по запросу владельца «проверки на соответствие»). Кратко:

- **Структура совпадает** (сильно): T5/T7 (локальное правило по своей позиции `c_j`, без D
  и чужих цен — `detect_and_emit_band_breach_locked`), T6 (внутренняя биржа бесплатна,
  `CE_COMMISSION_IN_POLKA=false`), T2 (наклон = ликвидность). Архитектурный скелет CE
  соответствует главному тезису «Предложения 2».
- **Расхождения — в калибровке коэффициентов и одной архитектурной развилке:**
  1. Масштаб band-порога по γ: CE `∝1/γ` (`Γ=γσ²τ`, ADR-066) vs статья `∝1/√γ`
     (`Q_i=ω_i c_i/A`, `A=σ√(2γ/Λ)`); нет веса `ω_i=φ2+B`. **Материально; addendum к ADR-066.**
  2. Inventory-skew: CE плоская `ce_inv_skew_gamma` vs статейное `A=σ√(2γ/Λ)`. Калибровка.
  3. Арбитражёр A_*: в статье отдельной сущности НЕТ (арбитраж эмерджентен из пары
     Переводчиков + внутр. биржи); CE вводит агента с рыночным round-trip хеджем → лишний
     рыночный риск (уже задокументировано ADR-065 как MVP-долг). **Материально для риск-профиля.**
  4. Нет явного `B·D` в якоре и смеси `w·P+(1−w)·Pλ` — CE решает через внутренний клиринг;
     косметика по духу.
- Вне периметра: T8 (ценность координации 2×), T9 (непрерывный decay `−rq` — CE ступенчато),
  T10 (осторожный конвейер Ψ).

Полный аудит — в диалоге сессии (2026-09-28). Следующий шаг (по решению владельца):
addendum к ADR-066 по расхождению #1.
