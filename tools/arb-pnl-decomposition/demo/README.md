# Проверка демонстрационного расчёта клиринга CE

`demo_core.js` — ядро файла «Интерактивный_клиринг_CE 4.html» (блок `//==CORE==`, логика без изменений).

- `node demo_check.js` — сверка с числами документа «Кривые котирования» (случай B, §8.2: оборот 396,05 USDT, выгоды 1,57 / 0,78 / 1,57, курсы 60 477 и 60 717, натуральная прибыль связки 0,000026 BTC) и внутренние тождества демо (неттинг, закрытие ведомости, Σ S = ½ Σ w·δ, неотрицательность выгод, независимость потоков от калибровки узла).
- `node two_venue_case.js` — простейший случай «две биржи, один актив»: денежный результат участников при трёх способах закрыть позицию связки (физический перевод, рыночное закрытие «в свою сторону», рыночное закрытие с перевёрнутыми знаками).

Описание и выводы: `docs/experiments/EXP-2026-10-22-ce-theory-conformity.md`.
