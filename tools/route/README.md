### Почему не дотягивает (структурно, не баг)

1. **Якорь.** UC-карточки имеют короткие, общие заголовки (`UC-F18-04` —
   «Такт клиринга...», «UC-F18-03» — др.) — при малом числе слов в title
   нормировка `overlap / sqrt(len(title_tokens))` даёт им несправедливо
   высокий score против более специфичных, но многословных title CALC/CAP.
   Частичный фикс (нормировка длины, UI-boost по screen-лексике) поднял
   anchor 5→11/20, дальше — нужна либо лучшая токенизация (стемминг,
   биграммы), либо реальный эмбеддинг — за рамками «без LLM, <200мс».
2. **Верхняя точка для `fix`.** §3.4 говорит «уровень, чьё правило
   нарушено» — это требует знать ПОЧЕМУ наблюдение неверно (дисплей не
   синхронизирован vs формула неверна), а не только ЧТО наблюдение
   описывает. Текстовый скорер этого не знает — эвристика (подняться до
   CALC в цепочке) угадывает верно для «формула иначе», неверно для
   «два экрана показывают разное» (там баг обычно на Р8, а не Р4).
3. **Класс для `ask`/`describe`.** Класс по §3.6 предполагает, что
   верхний уровень ИЗМЕНЯЕТСЯ; у читающих типов класс зависит от того,
   полна ли цепочка документации — это семантическое сравнение (шаги 3-5
   алгоритма §3.5), не текстовый поиск. Сделал явный дефолт `S` для
   `ask`/`describe` (см. комментарий в `route.py::class_from_top`), а не
   попытку угадать разрыв.

### Что это значит для принятия решения

Нешаблонный, явный без-LLM маршрутизатор на substring/word-overlap
структурно не дотягивает до заявленного порога на реальных репликах —
не из-за недостроенности (markers.yaml/нормировка можно тюнить и
дальше), а потому что часть алгоритма §3.5 (шаги 2-6: runtime-first,
горизонтальный переход, различение «баг дисплея» vs «баг формулы»)
принципиально требует контекста/суждения, которого у чистого keyword-
скорера нет. `route.py --candidates` даёт *кандидатов* для подъёма
(§3.5 шаг 1) — не замену шагов 2-6. Решение по порогу (принять как есть
+ --candidates используется как подсказка, не автоматический вердикт;
снизить порог; добавить легковесный классификатор без полного LLM) —
за владельцем, не принимаю здесь сам.
